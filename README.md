## 为什么做这个仓库

机场的价格和定位变化很快，网上流传的大量价格表没有日期、没有来源，很多已经过期（实例：本站 2026-11-06 核验维云云时，测评文写的月付 18 元起、本站旧页面写的 4 元包月都已过期，官网现行价为 5 元 / 100G 起）。本仓库只做一件事：把价格和它的来源、日期钉在一起，持续滚动更新。

## 来源类型说明（口径分级）

- **官网核验**：核验日当天在商家官网价目页逐档读取。
- **商家标价整理**：商家在本站条目中公开标示的价格，本站整理成表，未在官网价目页复核（部分商家官网只有登录面板、不公开价目）。
- **测评资料口径**：多家 2026 年测评资料交叉一致的价格，商家官网面板价目可能略有出入。
- **待复核**：官网在核验日不可达，价格维持旧登记并明确标注，不作为现行价推荐。

## 核验与更新方法

- 每档价格带 `verified_date`；来源或日期缺失的数据不收录。
- 滚动复核：每天轮查 2–3 家，官网有公开价目的直接对价，面板站只查存活；发现调价即更新 CSV 并记入 `CHANGELOG.md`。
- 线路类型（专线 / 中转等）均为商家自称口径，本站未做测速背书；本数据集不含任何测速结论。

## 免责

- 本数据集是价格信息整理，不是购买推荐；商家随时可能调价或停止运营，下单前请以官网实时价格为准。
- 任何机场第一次购买都建议先月付试用，不要直接长周期预付。
- 本仓库内所有链接均为裸链接，不含推广 / 返佣参数。
